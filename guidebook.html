시스템 개요

KCH Purchase Plan은 회사 내부의 석탄 구매 계획 및 가격 관리 플랫폼입니다. 연간 구매 화물(Cargo)을 추적하고, 가격 정보를 기록하며, Argus ICI 지수와 연동하여 아직 결제되지 않은 지수 연동 화물의 가격 예측 및 리스크 판단을 지원합니다.

시스템은 사내 브라우저에서 실행되며 별도 소프트웨어 설치가 필요하지 않습니다. 지정된 주소에 접속하면 바로 사용할 수 있으며, 데이터는 실시간으로 공유됩니다.

3

월별 구매 계획 (Monthly Plan)

시스템의 메인 화면으로, 지정된 월의 구매 KPI 요약, 전체 화물 목록, ICI 지수 추세 차트를 표시합니다.

3.1   월/연도 전환

화면 상단에 월 탭(Jan — Dec)과 연도 좌우 화살표가 있습니다.

  • 1
    월 탭(예: Jun)을 클릭하여 해당 월 데이터를 조회합니다.
  • 2
    연도 옆 ‹ ›를 클릭하여 전년도 / 다음 연도로 이동합니다.
  • 3
    맨 오른쪽 Total을 클릭하면 연간 전체 합산을 조회합니다.

3.2   KPI 카드 의미

월을 선택하면 상단에 6개의 KPI 카드가 표시됩니다.

KPI 카드의미

Fixed Price고정 가격 화물 수량
Index Price지수 연동 가격 화물 수량
Sold판매 완료된 화물 수량
For Sale판매 중, 아직 거래 미성사 화물 수량
Planned계획 중, 아직 확정되지 않은 화물 수량

각 카드 하단에 전월 대비 증감률이 표시됩니다 (초록색 ▲ 상승, 빨간색 ▼ 하락).

3.6   ICI 지수 차트

화면 우측(또는 하단)에 Argus ICI 지수 히스토리 추세 차트가 표시됩니다. ICI2 / ICI3 / ICI4 / ICI5 탭을 클릭하여 각 지수의 역사적 가격 곡선을 확인하고 시장 동향을 파악할 수 있습니다.

ICI 지수 소개: ICI(Indonesia Coal Index)는 Argus가 발행하는 인도네시아 석탄 주별 기준 가격 지수입니다. ICI2 = NAR 5000 kcal, ICI3 = NAR 4200 kcal, ICI4 = NAR 3800 kcal, ICI5 = NAR 3400 kcal. 가격 단위는 $/t (미달러/톤)입니다.

3.7   화물 행 클릭 → 가격 산정 워크벤치 진입

화물 목록의 임의 행을 클릭하면 해당 화물 전용 '가격 산정 워크벤치' 화면으로 이동하여 심층적인 가격 분석 및 판단을 수행할 수 있습니다.

💡 참고: 워크벤치 확인 후 좌측 상단 ← Back to Plan을 클릭하면 화물 목록으로 돌아갑니다.
4

화물 가격 산정 워크벤치 (Pricing Workbench)

가격 산정 워크벤치는 본 시스템의 핵심 기능 중 하나로, 지수 연동 가격의 판매 중 화물을 위해 설계되었습니다. 지수 발표 전에 가격 추세를 미리 판단하고, 매입/관망/회피 등 운영 의사결정을 내릴 수 있도록 지원합니다.

주의: 본 워크벤치는 $/t (톤당 가격)만 표시하며, 총금액이나 이익은 표시하지 않습니다. 구매 관점의 순수성을 유지하기 위한 설계입니다.

4.1   워크벤치 진입 방법

  • 1
    월별 계획(Monthly Plan) 화면에서 대상 화물을 찾습니다.
  • 2
    해당 행을 직접 클릭하면 해당 화물의 가격 산정 워크벤치로 자동 이동합니다.
  • 3
    워크벤치 상단에 화물명, 연월, 상태, 가격 유형이 표시됩니다.

4.2   좌측 패널: 화물 기본 정보

항목의미
Mine광산명 (예: Adaro)
Spec석탄 규격 (예: NAR4400)
Status현재 상태 (For Sale / Sold / Planned)
Buyer바이어 (미판매 시 "—")
Quantity계약 수량
Laycan선적 기간 (예: 1–30 Jun)
Purchase Date구매 일자
Formula지수 가격 공식 (예: ICI3/4600*4400+2.75)
Index Rule가격 산정 규칙 (예: "1 month before laycan")
Pricing Period시스템이 자동 계산한 참조 기간 (예: May 2026 avg)

4.3   우측 상단: ICI 참조 데이터

시스템은 화물의 가격 산정 규칙(예: "1 month before laycan")에 따라 자동으로 참조 기간(예: Laycan 6월 → 참조 기간 5월)을 결정하고, 해당 기간의 모든 ICI 주별 데이터를 나열합니다.

표는 공식에 사용된 지수 컬럼만 표시합니다 (예: 공식이 ICI3이면 ICI3 컬럼만 표시, 나머지 불표시).

행 유형표시의미
Actual (발표 완료) Actual Argus가 공식 발표한 실제 ICI 가격으로, 수정 불가
Forecast (예측) Forecast 아직 발표되지 않은 주별 데이터. 편집 가능한 입력란으로 표시되어 예측값 수동 입력 가능
Avg (평균) 마지막 행 현재 모든 주별 데이터(예측 포함)의 월평균 가격. 결제가 계산의 기준
💡 핵심 기능: Forecast 행의 입력란에 ICI 예측 가격을 입력하면 월평균과 최종 결제가가 실시간으로 자동 업데이트됩니다. 별도 계산 없이 "현재 가격이 유리한가"를 즉시 판단할 수 있는 핵심 도구입니다.

4.4   결제 공식 바

참조 데이터 표 아래에 짙은 색 배너가 표시되며, 다음 내용을 포함합니다.

  • 좌측: 계약 가격 공식 (예: ICI3/4600*4400+2.75)
  • 우측: 현재 월평균 기준으로 계산된 예상 결제가 ($/t)

Forecast 행 데이터를 수정하면 우측 결제가가 즉시 변경됩니다.

4.5   우측 중단: 결제가 민감도

ICI 지수 전체가 $1/$2/$3/t 상승 또는 하락할 경우 결제가가 어떻게 변하는지 보여주는 표입니다.

4.6   우측 하단: 구매 가격 판단 (Procurement Price Judgment)

해당 화물에 대한 구매 담당자의 주관적 판단을 기록하는 영역입니다. 저장하면 시스템에 반영되고, 화물 목록의 광산명 아래에 표시됩니다.

항목옵션 / 설명
Direction (시장 방향) Bull 강세  |  Neutral 중립  |  Bear 약세
Action (운영 제안) Buy now (즉시 매입) / Wait (관망) / Lock index (지수 고정) / Watch (모니터링) / Avoid (회피)
Target $/t 목표 결제가 (달러/톤), 예: $82.00
Note 비고: 시장 의견, 공급 조건, 판단 근거 등 자유 텍스트
  • 1
    Direction과 Action을 선택합니다 (해당 버튼 클릭 → 선택 시 하이라이트).
  • 2
    Target $/t와 Note를 입력합니다 (선택 사항).
  • 3
    Save Judgment를 클릭하여 저장하면 우측 상단에 저장 시간이 표시됩니다.
💡 저장 후 효과: 화물 목록에서 해당 화물의 광산명 아래에 간략한 태그가 표시됩니다. 예: Bull · Wait · $82.00/t 목록 화면에서 모든 화물의 판단 상태를 한눈에 파악할 수 있습니다.

가격 예측 (Price Forecast)

상단 Price Forecast 탭을 클릭하여 진입합니다. 향후 수 주간의 ICI 지수 예측값을 관리하고, 모든 지수 연동 화물의 예상 결제가를 자동으로 계산합니다.

5.1   상단 컨트롤 바

컨트롤설명
Base 태그최신 발표된 ICI3 가격 표시 (기준 참조)
Trend 선택기
Flat / +1%/wk / -1%/wk 등		선택 시 데이터가 없는 예측 행에 해당 추세로 자동 값 입력
Show history / Hide history당해 연도 과거 월 ICI 데이터 표시/숨기기 (기본: 현재 월 이후만 표시)
+ Week예측 매트릭스 하단에 행 추가 (더 먼 미래 주 수동 추가용)
Save Forecast현재 예측 데이터를 시스템에 저장하여 팀 전체와 공유

5.2   주별 ICI 예측 매트릭스

표에 주 단위로 각 ICI 데이터가 나열되며, 두 가지 행 유형이 있습니다.

  • 회색 행 (Actual): Argus가 공식 발표한 주별 ICI 데이터. 읽기 전용
  • 흰색 행 (Forecast): 아직 발표되지 않은 예측 행. ICI2–ICI5 수동 입력 가능, Note 컬럼에 메모 작성 가능
주의: 예측 행 수정 후 반드시 Save Forecast를 클릭해야 저장됩니다. 저장하지 않으면 새로고침 시 데이터가 초기화됩니다.

5.3   월평균 가격 요약

예측 매트릭스 아래에 월별 평균가 요약 표가 있으며, ICI2–ICI5의 월 평균값(발표 완료+예측 데이터 합산)을 표시합니다. 해당 월 데이터가 "Actual"(전체 발표 완료), "Forecast"(전체 예측), "Partial"(혼합) 중 어느 상태인지 함께 표시됩니다.

5.4   화물 결제 매트릭스 (Cargo Settlement Matrix)

화면 하단에 미판매 지수 연동 화물과 예상 결제가가 모두 표시되며, 가격 민감도 조정을 지원합니다.

용어집

ICI (Indonesia Coal Index)
Argus가 매주 발표하는 인도네시아 석탄 기준 가격 지수. ICI2 (NAR5000), ICI3 (NAR4200), ICI4 (NAR3800), ICI5 (NAR3400)로 구분됩니다.
NAR / GAR
NAR = Net As Received (도착 기준 순 발열량); GAR = Gross As Received (총 발열량). 동일 석탄의 경우 GAR > NAR이며, 환산 계수는 약 0.96입니다.
Laycan
선박 선적 기간 (Loading + Cancellation). 계약에서 규정한 선박의 입항 및 선적 가능 기간입니다.
Index Rule (가격 산정 규칙)
계약에서 어느 기간의 ICI 평균 가격을 결제에 적용할지 정한 규칙. 대표 유형: 1 month before laycan (Laycan 전월 평균), 4 weeks before laycan (Laycan 전 4주 평균), 3 weeks before laycan.
Pricing Period (가격 산정 참조 기간)
Index Rule과 Laycan 날짜를 기반으로 시스템이 자동 계산한 실제 참조 기간. 예: "May 2026 avg".
Settlement (결제가)
계약 공식(예: ICI3/4600*4400+2.75)에 가격 산정 참조 기간의 ICI 평균을 대입하여 계산된 최종 구매 결제가 ($/t).
Sensitivity (민감도)
ICI 지수가 가정상 상하 변동(예: ±$1/t)할 때 최종 결제가에 미치는 영향 분석. 가격 리스크 평가에 활용됩니다.
Judgment (가격 판단)
구매 담당자가 특정 화물에 대해 시장 방향(Bull/Neutral/Bear)과 운영 행동(Buy now/Wait 등)을 기록하는 주관적 판단. 저장 후 팀 전체가 공유 조회 가능합니다.
Fixed Price
고정 가격 계약. 계약 시점에 가격이 확정되며 지수 변동의 영향을 받지 않습니다.
Index Price / Floating Price
지수 연동 가격 계약. 최종 결제가가 특정 기간의 ICI 평균에 따라 공식으로 계산되므로 가격 변동 리스크가 존재합니다.
For Sale Plan
판매 중인 구매 계획. 즉, 바이어를 아직 찾지 못한 화물 목록으로, 영업팀의 외부 오퍼 기준이 됩니다.
